# Географическая викторина GeoQuiz

Интерактивное веб-приложение для проверки знаний географии в игровой форме.

## Возможности

- 🗺️ Интерактивная карта с кликабельными маркерами
- ⭐ Система подсчета очков (точность + скорость)
- ⏱️ Таймер на каждый вопрос
- 💡 Подсказки к вопросам
- 📊 Таблица лидеров
- ➕ Возможность добавлять свои вопросы

## Технологии

### Фронтенд
- React 18
- Leaflet / React-Leaflet
- TailwindCSS
- Socket.io-client
- Axios

### Бэкенд
- Node.js / Express
- PostgreSQL + PostGIS
- Redis
- JWT аутентификация
- Socket.io
