Отчет об использовании AI-инструментов в разработке GeoQuiz

1. Применённые инструменты и промпты

Использованные AI-инструменты:

    ChatGPT-4 - для проектирования архитектуры, отладки сложных ошибок и написания документации

    DeepSeek - для рефакторинга и оптимизации существующего кода


Ключевые промпты и их назначение:
    Промпт 1: Проектирование архитектуры приложения
    Запрос: "Спроектируй архитектуру веб-приложения для географической викторины. 
    Нужно: интерактивная карта на Leaflet, система подсчета очков с учетом точности и скорости, 
    таблица лидеров, возможность добавлять вопросы. Какая должна быть структура БД? "

    Промпт 2: Реализация формулы расстояния:
    Запрос: "Напиши функцию на JavaScript для расчета расстояния между двумя точками на сфере 
    по формуле гаверсинуса. Координаты приходят в градусах, нужно вернуть расстояние в километрах. 
    Добавь комментарии и пример использования."


2. Где AI оказался наиболее полезен:

- Генерация шаблонного кода ✨

Создание базовой структуры приложения
Написание CRUD операций для Mock API

- Отладка сложных ошибок 🔍

Помог найти проблему с неочищающимися маркерами
Объяснил, как работают event listeners в Leaflet

- Документирование кода 📝

Автоматически сгенерировал JSDoc комментарии
Помог составить README.md
Создал структуру API документации

- Объяснение концепций 

Разъяснил разницу между iconAnchor и iconSize в Leaflet
Объяснил принципы работы таймеров в JavaScript


3. Где AI ошибался:
- Неправильная формула расстояния:
    Ошибка: AI предложил использовать упрощенную формулу для плоской поверхности

    Обнаружение: При тестировании с удаленными точками 
    расстояние было в 2 раза меньше реального

    Исправление: Заменил на формулу гаверсинуса, объяснил AI ошибку, и он предложил 
    правильное решение

- Конфликт версий библиотек:

    Ошибка: AI сгенерировал код для React-Leaflet v3, но в проекте использовалась v4

    Обнаружение: При запуске в консоли были ошибки "Cannot read property 'on' of undefined"

    Исправление: Явно указал версию в промпте, AI обновил код


4. Основные выводы:

AI отлично подходит для рутинных задач, но требует проверки 
Быстро генерирует шаблонный код
Помогает с документацией

Однако: всегда нужно проверять математические расчеты и логику безопасности

Качество промпта определяет качество ответа 
Чем конкретнее вопрос, тем лучше ответ
Важно указывать контекст и версии библиотек


Помогает ускорить разработку, но не заменяет понимания основ
Важно знать, почему AI предложил то или иное решение
Критическое мышление остается ключевым навыком
